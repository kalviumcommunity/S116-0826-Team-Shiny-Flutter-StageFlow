# StageFlow

## Problem Statement

A regional theatre group manages auditions, rehearsal schedules, and cast assignments across several simultaneous productions, but coordination through group chats becomes unmanageable once multiple productions run in parallel. Cast members miss schedule changes, venues get double-booked, and directors have no consolidated view of commitments.

## Solution

StageFlow is a Flutter mobile application designed to centralize:
- Productions
- Auditions
- Casting and roles
- Rehearsals and performances
- Venue bookings
- Cast availability
- Notifications
- Conflict detection and resolution

## Target Users

- Director
- Cast / Performer
- Stage Manager
- Administrator

## Core Features

- Production management
- Audition scheduling and sign-ups
- Cast and role assignment
- Rehearsal/performance scheduling
- Venue booking
- Cast availability
- Schedule-change notifications
- Venue double-booking detection
- Cast commitment conflict detection
- Conflict resolution

## Technology Stack

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging
